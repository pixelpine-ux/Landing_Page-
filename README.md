# Dr. Sarah Belayneh - Therapist Landing Page

A professional potential landing page or a blog site .

## 🚀 Tech Stack

- **React** (v19) - UI Library
- **Vite** - Build tool and development server
- **Tailwind CSS** (v4) - Utility-first styling
- **Framer Motion** - Animations and transitions
- **Lucide React** - Iconography

## 🛠️ Prerequisites

Ensure you have **Node.js** (version 16 or higher) installed on your machine.

## 📦 Installation

1.  **Navigate to the project folder**:
    ```bash
    cd therapist-site
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

## 🏃‍♂️ Running the Project

Start the development server:

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173` (or the port shown in your terminal).

## 🏗️ Building for Production

To create an optimized build for deployment:

```bash
npm run build
```

The output files will be generated in the `dist` directory. You can preview the build locally using:

```bash
npm run preview
```

## 🎨 Customization

- **Colors & Fonts:** Modified directly in `src/index.css` using Tailwind v4 CSS variables.
- **Content:** Text and data (like FAQ items or Services) are contained within their respective component files in `src/components/`.
